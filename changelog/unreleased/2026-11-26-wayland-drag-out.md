- **Wayland windows start drags out** (`El::drag_out`): a `wl_data_source` handed to `wl_data_device.start_drag` offers files as `text/uri-list`, text as `text/plain;charset=utf-8` (and `UTF8_STRING`, `text/plain`) and PNG data as `image/png`, with the element's snapshot (or `DragItem::image`) as the drag icon; `on_drag_end` hears `Copied`, `Moved` or `Cancelled` from the compositor's `action`, `dnd_finished` and `cancelled` events, and the app's own windows take the drop only with `DragItem::within_app`. New `DragOperation::Ask` offers Wayland's ask action, so the target asks whether to copy or move; macOS and Windows ignore it. Before, `drag_out` was ignored on Linux; X11 windows and Wayland overlays still ignore it. Hyprland sends the source no action, so there a drop ends `Copied` even when the target moved the files.

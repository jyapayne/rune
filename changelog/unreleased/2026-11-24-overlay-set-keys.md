- `OverlayHandle::set_keys` changes an overlay's `KeyPolicy` while it runs, so a panel can take every key while the user walks its controls from the keyboard and give them back after. A shown Wayland layer surface asks for the new keyboard interactivity in a commit of its own (`Exclusive` with its focus grab), binds the keyboard and input method it now needs or lets them go, and a policy that takes no keys releases what keys held; a hidden one asks at its next show. X11 windows focus themselves by the new policy; Windows and macOS windows keep the activation style they were made with.
